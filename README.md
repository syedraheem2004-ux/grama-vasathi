# Grama Vasathi

**Grama Vasathi** is an Android application designed to bridge the gap between rural homestay hosts and travelers seeking authentic village experiences. 

## Features

- **Stay Discovery**: Browse and search for authentic rural homestays.
- **Booking Management**: Easy booking process for travelers.
- **Host Dashboard**: Management tools for village hosts.
- **Hygiene & Quality Focus**: Integrated hygiene scoring and ratings.
- **Firebase Integration**: Real-time database and authentication.
- **Local Persistence**: Powered by Room database for offline access.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM with Clean Architecture principles.
- **Dependency Injection**: Hilt
- **Database**: Room
- **Backend**: Firebase (Auth & Real-time Database)
- **Image Loading**: Coil
- **Charting**: Vico

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio (Ladybug or newer).
3. Connect your own Firebase project by adding `google-services.json`.
4. Build and Run!
